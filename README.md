# 🏛️ University of Lucknow — ERP Management System

A complete College ERP web application built with:
- **Backend**: Core Java + Jakarta Servlet (EE 10) + JSP
- **Database**: MySQL 8.0
- **Server**: Apache Tomcat 10.1
- **Frontend**: HTML + CSS (Glassmorphism) + JavaScript

## 🌐 Live Demo
Deployed on Railway.app

- Timetable
- Complaints & Help Desk
- Dashboard Analytics

## 🚀 Local Setup
1. Clone this repo
2. Import `sql/complete_setup.sql` into MySQL
3. Run Tomcat 10.1 on port 8080
4. Copy `WebContent/` to `webapps/CollegeERP/`
5. Open `http://localhost:8080/CollegeERP/`
